SOLAR & ELECTRICAL SOLUTIONS GUIDE — WDD231 W06 STARTER

Copy this solar-guide folder into your existing wdd231 repository.
Open the repository in VS Code and use Live Server to test solar-guide/index.html.
Test equipment.html using Live Server because Fetch API does not work reliably from file:// URLs.
Replace the video placeholder in each footer with your public 3–5 minute demonstration URL.
Add citations to attributions.html for any external resources you use.
Update the Final link in the root W01 page navigation to solar-guide/index.html.

Included: three main pages, a form action page, attributions page, 15 equipment records,
Fetch API, async/await, try/catch, ES modules, array methods, template literals,
DOM manipulation, Local Storage preference, modal dialog, responsive navigation and layouts.

This is a starter implementation. Personalise, test, run the W06 audit and Lighthouse on all
three main pages, check CSS Overview contrast, and record your own face-and-screen video.
Equipment specifications are educational examples, not installation instructions. Verify
real designs against manufacturer data and applicable electrical standards.
